# Wallet branding

`btcw_wordmark.png` is the original image supplied by the user.
`btcw_coin.png` is bundled from the requested BitcoinPoW node asset:
https://github.com/bitcoin-pow/BitcoinPoW/blob/new_fork_no_ext_work_no_pools/src/qt/res/icons/bitcoin.png

Both assets are bundled locally; screen rendering requires no remote image fetch.
The shared header retains a white background for the original black lettering,
including in dark mode. QR codes retain a white background and quiet zone.
